# Fontes das vitrines de demonstração (/sites/vitrine/)

Negócios **fictícios** (Fornalha Burger, Barbearia Ofício), criados para mostrar o nível do trabalho. Páginas com `noindex`, selo "Demonstração · negócio fictício" e depoimentos marcados como ilustrativos. Os botões de WhatsApp falam com o José.
